### IP Address
- Unique identifier of a device

### CIDR
- A private network is an isolated block of networks
- A range of IP addresses that make up an isolated network (private network)
- All private networks will have a `CIDR (Classless Inter Domain Range)`
- `16.10.19.98/28`; the number after the forward slash - `called subnet mnasking` - is a denotion of how many IPs can be accommodated within the network.
- The list of IPs within the CIDR is private.
